# v0.2.0 - Evidence-Bounded Reflection and Privacy Gate

This release expands the skill from narrative reconstruction into disciplined
career, family-power, relationship, and counterfactual analysis.

## Highlights

- separates facts, recollections, inferences, hindsight, and counterfactuals
- anchors past decisions to the information available at the time
- distinguishes coercive effect from unproven intent
- distinguishes adaptive relationship changes from betrayal
- treats effort, structural conditions, timing, and luck separately
- adds a public-release gate for quasi-identifiers and rare combinations

## Added

- detailed analysis frameworks for counterfactuals, power, relationships, and
  professional boundaries
- a privacy and public-release checklist
- a local scanner for common identifiers, paths, and credentials
- improved analytical templates and deliberately generic examples
- Codex UI metadata

## Privacy

The repository contains no source chronology or real-life case material. The
scanner supports release hygiene but does not prove anonymity; manual review
for re-identification by combination remains required.
